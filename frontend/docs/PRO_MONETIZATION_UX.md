## 1. Featured Listing Badges

### Where to Show
- Listing cards in search results
- Listing detail page header
- Home page featured section
- Category pages

### UX Copy

**Badge Text Options:**
| Turkish | English | Context |
|---------|---------|---------|
| `Öne Çıkan` | Featured | Standard badge |
| `⭐ Premium` | Premium | High-tier badge |
| `🔥 Popüler` | Popular | Performance-based |
| `✓ Doğrulanmış` | Verified | Trust signal |
| `🏆 Editörün Seçimi` | Editor's Pick | Curated |

**Tooltip/Hover Text:**
- TR: "Bu ilan organizatör tarafından öne çıkarılmıştır"
- EN: "This listing has been featured by the organizer"

**CTA for Non-Featured:**
- TR: "İlanınızı öne çıkarın, %40 daha fazla görüntülenme alın"
- EN: "Feature your listing, get 40% more views"

## 2. Request Priority

### Where to Show
- Request submission form (upgrade prompt)
- Request list (priority indicator)
- Organizer inbox (boosted requests)

### UX Copy

**Priority Levels:**
| Level | Badge | Benefits |
|-------|-------|----------|
| Standard | None | Normal visibility |
| Priority | 🚀 Öncelikli | 2x visibility, top placement |
| Urgent | ⚡ Acil | Instant notification to all vendors |

**Upsell Messages:**

│ 🚀 Talebinizi Öncelikli Yapın      │

"Henüz yanıt almadınız mı? Talebinizi öne çıkararak 
organizatörlerin dikkatini çekin. Ortalama yanıt süresi

## 4. Conversion Triggers

### Timing-Based

| Trigger | Message |
|---------|---------|
| 3 days no response | "Talebiniz yanıt bekliyor. Öne çıkararak hızlandırın." |
| Listing views drop | "Görüntülenmeleriniz düştü. Öne çıkararak canlandırın." |
| Competitor featured | "Rakipleriniz öne çıktı. Siz de dahil olun." |
| End of trial | "Pro denemeniz bitiyor. Şimdi abone olun, %20 indirim." |

### Social Proof

```
"Bu hafta 47 organizatör Pro'ya geçti"
"Pro organizatörler ortalama 3.5x daha fazla talep alıyor"
"En çok tercih edilen plan: Pro ⭐"
```
